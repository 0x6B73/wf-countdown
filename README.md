# WoW Forever countdown

A whimsical, responsive, standalone fan countdown. Open `index.html` in any browser. No build, external assets, or dependencies required.

Launch: **November 4, 2026, 3:00 PM PST**, stored as `2026-11-04T23:00:00Z`. The timer uses the current clock and an absolute UTC release timestamp, so it survives refreshes and daylight saving changes. At zero it switches to a launch message.

## GitHub Pages

Upload `index.html` and `.nojekyll` to the repository root. Under **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

For `0x6B73/wf-countdown`, the address will be https://0x6b73.github.io/wf-countdown/ once deployment completes.

GitHub documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
